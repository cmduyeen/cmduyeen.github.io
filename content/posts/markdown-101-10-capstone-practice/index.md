*Markdown 101 · Part 10/10*

To tie together everything in **Markdown 101**, write a complete 200–300 word article combining headings, paragraphs, ordered lists, a summary table, a blockquote, a code block, and a descriptive link—then download the `.md` file for your own vault.

## Capstone Requirements

A well-structured technical note or blog post should include:

1. **A direct opening**: 1–2 sentences answering the core topic immediately.
2. **Two clear `##` sections**: paragraphs separated by blank lines.
3. **One ordered list (`1.`) or checklist (`- [ ]`)**.
4. **One summary table (`| ... |`)** or **fenced code block (` ``` `)** with a language tag.
5. **One blockquote (`>`)** and **one descriptive source link (`[label](url)`)**.

## Self-Review Table Before Publishing

| Check | Passing Standard |
| --- | --- |
| Heading hierarchy | No duplicate `H1`; subsections follow `##` → `###` |
| Encoding | Saved in UTF-8 without broken characters |
| Links & paths | Internal links use `/en/posts/...`; no local drive paths |
| Code fences | Every opening ```` ``` ```` has a matching closing fence |
