Tổng hợp các công cụ web chạy trực tiếp trên trình duyệt, không cần cài đặt hay mua tên miền:

- **[Pro GitHub Starter Kit — Profile Builder](https://cmduyeen.github.io/pro-github-starter-kit/)**  
  Tạo trang GitHub Profile README đẹp trong 60 giây với 9 theme, 12 plugin và khung xem trước Dark/Light song song.

- **[Pro Blog Starter Kit — Blog Configurator](https://cmduyeen.github.io/pro-blog-starter-kit/)**  
  Cấu hình nhanh blog cá nhân Hugo hoặc Jekyll miễn phí trên GitHub Pages, xuất file cấu hình và workflow tự động deploy.

- **[Lịch Âm Việt Nam (.ics)](https://github.com/cmduyeen/lich-am-viet-nam)**  
  Lịch âm chuẩn Việt Nam (GMT+7) cho Google Calendar, Apple Calendar và Outlook — chỉ cần gắn link URL dùng luôn.

- **[Serein & Pinkie Themes](https://github.com/cmduyeen/serein-theme)**  
  Hệ thống bảng màu tối giản cho VS Code, Neovim, Obsidian và Terminal ([Serein](https://github.com/cmduyeen/serein-theme) · [Pinkie](https://github.com/cmduyeen/pinkie-theme)).
