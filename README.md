# Dyn

Blog cá nhân tiếng Việt, dựng bằng Hugo và lưu trữ trên GitHub Pages. Giao diện tĩnh tối giản, tự đổi sáng/tối theo thiết bị, không dùng JavaScript hay theme bên ngoài.

## Viết và xuất bản

Tạo bài Markdown trong `content/posts/`. Nội dung trong thư mục này được xuất bản công khai. Đẩy thay đổi lên `main`; GitHub Actions sẽ tự dựng và triển khai website.

## Xem trước

Cài Hugo 0.146.0 rồi chạy:

```powershell
hugo server -D
```
